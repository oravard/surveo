# Langue
Toujours communiquer en français avec moi — explications, commentaires, 
messages de statut compris. Le code, les noms de variables et les 
commandes restent en anglais comme d'habitude.


# Spécification et réalisation
- SPEC.md dit ce que fait Surveo, vu de l'utilisateur : syntaxe, règles,
  messages, critères d'acceptation, décisions de l'utilisateur. Il est rangé
  par thème.
- IMPL.md dit comment c'est réalisé, tel que le code est aujourd'hui :
  architecture, fichiers, tests, mesures, limites. Un travail proposé ou en
  cours y garde son ordre de réalisation ; une fois fait, il est décrit
  au présent, sans le journal de ses étapes.
- Une nouvelle proposition s'écrit dans SPEC.md, dans le chapitre de son
  thème ; sa réalisation dans IMPL.md, dans une section du même titre, au
  chapitre du même thème.
- Dans le code, un commentaire renvoie à SPEC.md pour une règle, à IMPL.md
  pour l'architecture.
