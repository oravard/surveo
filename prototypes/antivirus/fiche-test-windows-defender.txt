Surveo - prototype 6 (antivirus) - fiche de test, Microsoft Defender ACTIF
==========================================================================

OBJECTIF : mesurer la reaction TEMPS REEL de Microsoft Defender aux trois
binaires NON SIGNES, sur une machine ou Defender est l'antivirus ACTIF
(aucun antivirus tiers). C'est le cas le plus repandu dans les lycees qui
n'ont pas de produit tiers. Sur le PC de test precedent, Defender etait
passif derriere Avast : il n'avait donc pas pu etre mesure.

On ne desactive rien. Un blocage est un resultat a noter, pas a contourner.

ENVIRONNEMENT : VM Windows 10 ou 11 propre, a jour, SANS antivirus tiers.

1. VERIFIER QUE DEFENDER EST BIEN L'ANTIVIRUS ACTIF (PowerShell)
   Get-MpComputerStatus | Select AMRunningMode, RealTimeProtectionEnabled, `
     AntivirusEnabled, IsTamperProtected, AMProductVersion, AMEngineVersion
   -> attendu : AMRunningMode = "Normal", RealTimeProtectionEnabled = True
   # Protection cloud + envoi d'echantillons ACTIVES (reaction reelle) :
   Get-MpPreference | Select MAPSReporting, SubmitSamplesConsent
   # si besoin (PowerShell en administrateur) :
   Set-MpPreference -MAPSReporting Advanced -SubmitSamplesConsent SendAllSamples

2. PREPARER LES BINAIRES
   Copier capture.exe, classifieur.exe, sans-admin.exe dans Documents.
     cd $HOME\Documents
   Verifier les empreintes contre empreintes.sha256 (binaires de reference) :
     Get-FileHash capture.exe, classifieur.exe, sans-admin.exe -Algorithm SHA256
   Poser la marque "telecharge depuis Internet", pour que SmartScreen soit
   consulte comme dans la vraie vie :
     '[ZoneTransfer]',"ZoneId=3" | Set-Content -Path .\capture.exe     -Stream Zone.Identifier
     '[ZoneTransfer]',"ZoneId=3" | Set-Content -Path .\classifieur.exe -Stream Zone.Identifier
     '[ZoneTransfer]',"ZoneId=3" | Set-Content -Path .\sans-admin.exe  -Stream Zone.Identifier

3. SMARTSCREEN AU PREMIER LANCEMENT (chaque binaire)
   Double-cliquer capture.exe dans l'Explorateur.
   -> ecran bleu "Windows a protege votre ordinateur" / "editeur inconnu" ?
      Noter le texte exact, puis "Ne pas executer".
   Recommencer pour classifieur.exe et sans-admin.exe.

4. capture.exe - capture d'ecran repetee
   .\capture.exe --backend windows --duration 30 --continu
   -> Defender reagit-il (notification, quarantaine, blocage) ? Moment ?

5. classifieur.exe - analyse de texte locale
   .\classifieur.exe
   -> idem. C'est le binaire qui "lit du texte" : noter toute alerte.

6. sans-admin.exe - proxy FIXE
   .\sans-admin.exe installer
   -> reaction a l'inscription au demarrage de session ?
   .\sans-admin.exe filtrer bloquer example.com --duree 60
   -> reaction a la POSE DU PROXY ? (c'est ce qui avait declenche Avast
      IDP.Generic ; on veut savoir si Defender reagit aussi)
   .\sans-admin.exe desinstaller

7. sans-admin.exe - script PAC (comparaison)
   .\sans-admin.exe installer
   .\sans-admin.exe filtrer bloquer example.com --duree 60 --pac
   -> Defender reagit-il differemment du proxy fixe ? (la methode PAC
      pose une URL d'auto-configuration plutot qu'un proxy fixe)
   .\sans-admin.exe desinstaller

8. RELEVE DES DETECTIONS DEFENDER
   Get-MpThreatDetection | Sort-Object InitialDetectionTime |
     Format-Table InitialDetectionTime, ThreatID, Resources -Auto
   Get-MpThreat | Select ThreatName, SeverityID

A RENVOYER / a reporter dans resultats.md (nouveau poste "VM Defender",
colonne Signature = "non signe") :
  - Defender : version produit + moteur, AMRunningMode.
  - Pour chaque binaire : SmartScreen (oui/non) et reaction de Defender,
    avec le moment (lancement vs pose du proxy).
  - Pour sans-admin : difference entre proxy fixe (etape 6) et PAC (etape 7).
  - Noms de detection eventuels (etape 8).
